# Experiment results

This directory is the default destination for files generated by the experiment workflows.

At the current stage of the project, generated CSV result files are **not versioned in Git**. They are intentionally excluded through `.gitignore` and can be reproduced from the supplied scripts and notebooks.

The complete experiment produces:

```text
results/
├── per_run_results.csv
└── summary_results.csv
```

`per_run_results.csv` contains one row for every evaluated stream/configuration pair.

`summary_results.csv` contains the corresponding TP, FP, FN, FDR, MDR, IR, and Mean Delay values for:

- every detector × drift type × distribution combination;
- pooled rows across distributions;
- pooled rows across all evaluated scenarios.

Focused runs using one detector on one HDF5 archive are written under:

```text
results/selected/
```

with one per-run CSV and one summary CSV for the selected dataset/configuration pair.

## Article-style aggregation

The tables used for article reporting are generated from the distribution-specific rows of `summary_results.csv`.

For each detector and drift type, the metrics are averaged arithmetically across:

```text
normal
exponential
gamma
```

The pooled `distribution="all"` rows are not used for this article-level averaging.

The overall comparison is then obtained by averaging the three drift-level metric values for each detector:

```text
abrupt
gradual
incremental
```

For scenarios in which a detector produces only false alarms and no valid drift detections, the reporting utilities reproduce the article-style `NA` convention for metrics that are not meaningful.

Display these tables from the repository root with:

```bash
python scripts/show_results.py
```

or generate LaTeX output with:

```bash
python scripts/show_results.py --latex
```

The same reporting functions are available in `notebooks/run_experiments.ipynb` and are implemented in `src/mcdd/experiments/reporting.py`.
