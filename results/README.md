# Experiment results

This directory is the default destination for files generated by the experiment notebook.

At the current stage of the project, generated CSV result files are **not versioned in Git**. They are intentionally excluded through `.gitignore` and can be reproduced by running the experiment workflow described in the main README.

The complete experiment produces:

```text
results/
├── per_run_results.csv
└── summary_results.csv
```

`per_run_results.csv` contains one row for every evaluated stream/configuration pair. `summary_results.csv` contains the corresponding aggregated counts and metrics.

Focused runs using one detector on one HDF5 archive are written under:

```text
results/selected/
```

with one per-run CSV and one summary CSV for the selected dataset/configuration pair.

The final article-level aggregation across distributions is intentionally not implemented in this repository; it is performed separately from these generated results.
